1. Tentang Aplikasi

Try Out TKA Local Host adalah aplikasi ujian berbasis web yang berjalan sepenuhnya di laptop guru tanpa memerlukan koneksi internet. Siswa terhubung melalui Wi-Fi lokal (hotspot laptop atau Wi-Fi sekolah) dan mengerjakan soal dari browser HP/laptop masing-masing.

GambarDukung gambar di teks soal, opsi jawaban, dan pembahasan.

2. Instalasi & Menjalankan (Windows)

Pilihan A: Menggunakan Installer (.exe) — Disarankan

  1. Unduh file TKA-Setup-v...exe dari link yang diberikan guru/admin.
  2. Klik dua kali file tersebut.
  3. Jika muncul peringatan biru "Windows protected your PC", klik More info lalu Run anyway. (Ini normal karena aplikasi belum memiliki sertifikat digital berbayar).
  4. Ikuti proses instalasi (Next > Next > Install). Aplikasi akan terpasang di C:\TKA.
  5. Ikon TKA Local Host akan muncul di Desktop. Klik ikon tersebut untuk menjalankan.

Pilihan B: Versi Portable (.zip)

  1. Ekstrak file tka-local-windows-v...zip ke folder yang mudah diakses, misalnya D:\TKA.
  2. Buka folder tersebut, klik dua kali file start.bat.
Catatan Firewall: Saat pertama kali dijalankan, Windows mungkin memunculkan kotak dialog Firewall. Klik Allow access dan pastikan centang Private networks terpilih. Jika tidak diizinkan, HP siswa tidak akan bisa terhubung.

3. Membuat & Mengedit Paket Soal

Ada dua cara membuat paket soal: Import dari CSV (cepat untuk banyak soal) atau Edit langsung via UI (mudah untuk tambah gambar).

Menggunakan Editor UI (Direkomendasikan)

  1. Buka dashboard guru → menu Paket Soal.
  2. Klik tombol Edit pada paket yang sudah ada (atau import CSV dulu untuk paket baru).
  3. Di halaman editor, Anda bisa menambah soal, mengubah teks, memilih tipe soal (PG/MCMA/BS), dan mengatur kunci jawaban.
  4. Untuk menambah gambar, klik tombol 📷 Pilih Gambar. Anda bisa meng-upload file baru, atau melakukan Copy-Paste (Ctrl+V) screenshot langsung dari clipboard.
  5. Klik Simpan jika sudah selesai.

Menggunakan Import CSV

Buat file di Excel/LibreOffice, simpan sebagai CSV UTF-8. Format kolom:

no,tipe,soal,img,opsi_a,opsi_b,opsi_c,opsi_d,kunci,pernyataan_1,kunci_1,pernyataan_2,kunci_2,pembahasan
TipeCara Mengisi Kolom
pgIsi opsi_a s.d opsi_d. Kolom kunci = satu huruf (contoh: b).
mcmaIsi opsi_a s.d opsi_d. Kolom kunci = dua huruf atau lebih (contoh: ac).
bsIsi pernyataan_1 s.d pernyataan_5. Kolom kunci_1 s.d kunci_5 = B atau S.

Mode Acak Soal

Di editor paket, Anda bisa memilih:

  • Acak per tipe: PG dulu, lalu MCMA, lalu BS. Cocok untuk ujian formal.
  • Acak total: Semua tipe soal dicampur. Cocok untuk kuis singkat.
  • Tidak diacak: Urutan sesuai CSV (biasanya dari mudah ke sulit).
Urutan opsi jawaban (A/B/C/D) selalu diacak secara otomatis per siswa untuk mencegah siswa saling mencontek.

4. Mengelola Data Siswa

Data siswa dipakai untuk validasi login: siswa hanya bisa masuk jika namanya terdaftar.

  1. Buka menu Data Siswa di sidebar.
  2. Pilih file CSV dengan format: nis,nama,kelas (NIS dan kelas opsional).
  3. Pilih mode import: Tambah (menambahkan ke daftar) atau Ganti semua.
  4. Klik Import.
  5. Aktifkan toggle Wajib terdaftar. Jika aktif, siswa yang tidak ada di daftar akan ditolak saat login ujian.
Pastikan nama siswa yang diketik saat login persis sama dengan yang ada di CSV (huruf besar/kecil tidak masalah, tapi ejaannya harus sama).

5. Menjalankan Ujian

  1. Buka menu Dashboard.
  2. Pilih paket soal dari dropdown, lalu klik Mulai Ujian.
  3. Token 8 digit akan muncul di layar. Tulis di papan tulis atau tampilkan.
  4. Klik Perbesar untuk Proyektor pada QR Code agar siswa bisa scan langsung dari layar.
  5. Siswa membuka HP, scan QR / ketik alamat IP, lalu login menggunakan nama dan token.
  6. Pantau progress siswa di menu Peserta.
Penting: Waktu ujian mulai berjalan untuk semua siswa begitu Anda mengklik "Mulai Ujian". Pastikan siswa sudah siap sebelum Anda mengkliknya.

Akhir Ujian

  1. Server akan otomatis mengumpulkan jawaban (auto-submit) saat waktu habis.
  2. Klik tombol Rilis Pembahasan di Dashboard. Setelah ini, siswa bisa melihat kunci jawaban dan pembahasan di HP masing-masing.
  3. Klik Backup ZIP untuk menyimpan data hasil ujian ke komputer.

6. Mode Latihan Mandiri

Fitur ini memungkinkan siswa berlatih soal di rumah tanpa harus menunggu guru membuat sesi ujian (tidak butuh token).

Cara Guru Mengaktifkan:

  1. Buka menu Paket Soal.
  2. Pada baris paket yang diinginkan, klik tombol abu-abu Latihan: OFF hingga berubah menjadi hijau Latihan: ON.

Cara Siswa Mengakses:

  1. Buka halaman utama TKA di HP.
  2. Di bawah tombol login, klik tautan 🎓 Mode Latihan Mandiri.
  3. Pilih paket, isi nama, dan langsung kerjakan.
  4. Setelah selesai submit, pembahasan akan langsung terbuka.

7. Memantau & Analisis

Selama Ujian

Di menu Peserta, Anda bisa melihat siapa yang sudah selesai, sedang mengerjakan, dan berapa soal yang sudah dijawab. Anda juga bisa melihat jumlah pelanggaran (jika siswa pindah tab/aplikasi).

Analisis Butir Soal

Buka menu Analisis, lalu klik Muat Analisis setelah ujian selesai. Anda akan mendapatkan:

  • Statistik Kelas: Nilai rata-rata, tertinggi, terendah, dan standar deviasi.
  • Ranking Peserta: Urutan nilai siswa dari tertinggi.
  • Analisis Soal: Tingkat kesulitan soal (p-value) dan daya beda (D-index). Berguna untuk mengevaluasi kualitas soal.

8. Backup & Pemulihan

Setiap kali Anda menekan Mulai Ujian, sistem otomatis membuat backup database ke folder backups/ di laptop.

Backup Manual

Klik tombol Backup ZIP di Dashboard. File .zip akan terunduh. Simpan file ini di flashdisk atau Google Drive sebagai cadangan. ZIP berisi:

  • tka.db (Database siswa, jawaban, nilai)
  • paket/ (Semua soal)
  • paket/gambar/ (Semua gambar soal)

Pemulihan (Restore)

  1. Matikan aplikasi TKA.
  2. Ekstrak file ZIP backup.
  3. Timpa file/folder di direktori instalasi (misal C:\TKA) dengan file dari ZIP.
  4. Jalankan aplikasi kembali.

9. Panduan untuk Siswa

Login Ujian

  1. Pastikan HP terhubung ke Wi-Fi yang sama dengan laptop guru.
  2. Scan QR Code atau ketik alamat IP (contoh: 192.168.1.5:3000) di browser.
  3. Isi Nama Lengkap (sesuai absen), Kelas, dan Token dari guru.
  4. Klik Mulai Ujian.

Antarmuka Ujian

  • Tampilan Desktop: Jika menggunakan laptop, daftar nomor soal akan otomatis muncul di sebelah kanan layar.
  • Tampilan HP: Klik tombol ☰ Soal di pojok kanan atas untuk membuka daftar nomor soal.
  • Ragu-ragu: Klik tombol 🚩 Tandai Ragu jika Anda ingin meninjau soal tersebut nanti. Nomor soal akan berwarna kuning.
  • Auto-save: Setiap kali Anda menjawab, akan muncul tulisan "Tersimpan" di atas. Jika internet terputus (muncul tanda "⚠ Offline"), Anda tetap bisa menjawab. Jawaban akan otomatis dikirim saat internet tersambung kembali.
  • Shortcut Laptop: Gunakan tombol panah Kiri/Kanan untuk pindah soal, dan tombol R untuk menandai ragu-ragu.

Submit

  1. Klik tombol Selesai & Kirim di bagian bawah daftar soal (atau di bilah navigasi HP).
  2. Akan muncul konfirmasi berisi jumlah soal yang belum dijawab dan yang masih ragu. Periksa kembali.
  3. Klik Kirim Sekarang. Jawaban tidak dapat diubah setelah ini.

10. Troubleshooting

GejalaSolusi
HP siswa tidak bisa membuka halamanPastikan HP terhubung ke Wi-Fi yang sama. Cek Windows Firewall (izinkan Node.js di Private network).
Windows memblokir file .exeKlik "More info" lalu "Run anyway" pada peringatan Windows SmartScreen.
Siswa tidak bisa join (Nama tidak terdaftar)Matikan toggle "Wajib terdaftar" di menu Data Siswa, atau perbaiki ejaan nama di daftar siswa.
Import CSV gagalBaca pesan error. Pastikan kolom kunci terisi benar (huruf) dan tidak ada koma di dalam teks tanpa tanda kutip ("").
Server tiba-tiba matiBuka aplikasi TKA kembali (jika pakai .exe) atau jalankan start.bat. Data tidak akan hilang.
