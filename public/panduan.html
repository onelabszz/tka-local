1. Tentang Aplikasi

Try Out TKA Local Host adalah aplikasi ujian berbasis web yang berjalan sepenuhnya di laptop guru tanpa memerlukan internet. Siswa terhubung melalui Wi-Fi lokal (hotspot laptop atau Wi-Fi sekolah) dan mengerjakan soal dari browser HP masing-masing.

FiturKeterangan
Tipe soalPG (satu jawaban), MCMA (pilihan ganda kompleks), BS (Benar/Salah)
GambarDukung gambar di soal, opsi jawaban, dan pembahasan
Mode acakPer tipe, acak total, atau tidak diacak
Anti-cheatAcak urutan, log pindah tab, blokir copy/paste
Auto-saveJawaban tersimpan otomatis, tahan offline
AnalisisStatistik kelas, p-value, daya beda, distraktor
Latihan mandiriSiswa bisa berlatih tanpa token

2. Setup & Menjalankan

Pertama kali

  1. Buka terminal, masuk ke folder aplikasi: 
    cd ~/tka-local
  2. Jalankan setup sekali saja: 
    chmod +x install.sh start.sh
./install.sh
  3. Ikon TKA Local Host muncul di desktop dan menu aplikasi.

Setiap hari

  1. Klik ikon TKA Local Host di desktop.
  2. Tunggu 2–3 detik — browser otomatis terbuka ke dashboard guru.
  3. Terminal tidak perlu dibuka.
Tips: untuk menghentikan server, klik tombol Matikan Server di dashboard, atau tutup laptop seperti biasa.

3. Membuat Paket Soal

Format CSV

Buat di Excel/LibreOffice, simpan sebagai CSV UTF-8. Kolom:

no,tipe,soal,img,opsi_a,opsi_b,opsi_c,opsi_d,kunci,pernyataan_1,kunci_1,pernyataan_2,kunci_2,pembahasan
TipeIsi kolom
pgopsi_a–opsi_d, kunci = satu huruf (a/b/c/d)
mcmaopsi_a–opsi_d, kunci = dua huruf atau lebih (contoh: ac)
bspernyataan_1–pernyataan_5, kunci_1–kunci_5 = B/S

Langkah import

  1. Buka dashboard guru → sidebar Paket Soal
  2. Isi ID paket, Judul, Mapel, Durasi
  3. Pilih file CSV → klik Import
  4. Klik Preview untuk cek hasil

Menggunakan gambar

  1. Upload gambar di sidebar Gambar — catat nama filenya
  2. Di CSV, isi kolom img dengan nama file (contoh: peta.png)
  3. Untuk gambar di opsi, isi kolom opsi_a_img, opsi_b_img, dst

Mode acak

Di editor paket, pilih mode acak:

  • Acak per tipe (default) — PG dulu (acak), lalu MCMA, lalu BS. Cocok untuk ujian formal.
  • Acak total — semua soal dicampur. Cocok untuk kuis singkat.
  • Tidak diacak — urutan sesuai CSV. Cocok untuk ujian bertahap mudah → sulit.
Catatan: urutan opsi jawaban tetap diacak per siswa di semua mode — anti-cheat tetap jalan.

4. Mengelola Data Siswa

Data siswa dipakai untuk validasi login: siswa hanya bisa join kalau namanya ada di daftar.

Format CSV

nis,nama,kelas
2301,Budi Santoso,XI IPA 1
2302,Siti Nurhaliza,XI IPA 1
  1. Buka sidebar Data Siswa
  2. Pilih mode import: Tambah atau Ganti semua
  3. Pilih file CSV → Import
  4. Aktifkan toggle Wajib terdaftar
Penting: nama siswa harus persis sama (huruf besar/kecil tidak masalah) dengan yang diketik saat login.

5. Menjalankan Ujian

  1. Sidebar Dashboard → pilih paket
  2. Klik Mulai Ujian
  3. Token muncul di kotak besar
  4. Tampilkan QR code ke siswa (klik "Perbesar untuk Proyektor")
  5. Siswa scan QR atau ketik token di HP

Alur siswa

  1. Buka halaman siswa → isi nama, kelas, token
  2. Klik Mulai Ujian
  3. Kerjakan soal — setiap jawaban otomatis tersimpan
  4. Tandai soal ragu dengan tombol 🚩 Ragu
  5. Navigasi soal lewat grid di sidebar
  6. Klik Selesai & Kirim di footer sidebar
Tips: klik tombol Mulai Ujian setelah siswa siap — timer mulai berjalan untuk semua siswa saat itu juga.

Setelah ujian

  1. Klik Rilis Pembahasan agar siswa bisa melihat kunci dan pembahasan
  2. Buka sidebar Analisis untuk melihat statistik kelas
  3. Klik Backup ZIP untuk menyimpan semua data

6. Memantau & Analisis

Selama ujian

Sidebar Peserta menampilkan:

  • Nama, kelas, progress (dijawab/total)
  • Status: Mengerjakan / Selesai / Auto-submit
  • Jumlah pelanggaran (pindah tab)
  • Tombol Hapus untuk siswa yang salah masuk

Analisis butir soal

MetrikArti
p-valueProporsi siswa yang benar. > 0.7 = mudah, < 0.3 = sulit
D-indexDaya beda. > 0.4 = sangat baik, < 0.2 = perlu revisi
DistraktorSebaran pilihan salah. Yang tidak pernah dipilih = tidak berfungsi
FlagOtomatis menandai soal bermasalah
Butuh minimal 8 peserta untuk analisis daya beda yang bermakna.

7. Backup & Pemulihan

Backup otomatis

Setiap klik Mulai Ujian, sistem otomatis menyimpan salinan database ke folder backups/. Maksimal 14 file terakhir disimpan.

Backup manual

Klik Backup ZIP di dashboard → file tka-backup-YYYY-MM-DD.zip terunduh.

Isi ZIP:

tka.db              ← database
paket/              ← semua paket soal
paket/gambar/       ← semua gambar soal

Pemulihan

  1. Matikan server
  2. Extract isi ZIP ke folder ~/tka-local/ (timpa file lama)
  3. Jalankan server lagi

8. Panduan untuk Siswa

Login ujian

  1. Scan QR dari layar guru, atau buka alamat yang tampil di proyektor
  2. Isi nama lengkap, kelas, dan token dari guru
  3. Klik Mulai Ujian

Saat mengerjakan

  • Pilih jawaban — untuk PG klik satu opsi; untuk MCMA klik semua yang benar; untuk BS pilih B/S per pernyataan
  • Tandai ragu — klik tombol 🚩 Ragu jika ingin kembali lagi nanti
  • Navigasi — gunakan tombol Sebelumnya/Selanjutnya, atau klik nomor soal di grid
  • Status soal ditandai warna: biru = sudah dijawab, kuning = ragu, abu-abu = kosong

Submit

  1. Klik Selesai & Kirim di bagian bawah grid soal
  2. Konfirmasi akan menampilkan jumlah soal belum dijawab dan soal ragu
  3. Setelah kirim, jawaban tidak bisa diubah

Mode latihan mandiri

Di halaman login, klik Mode Latihan Mandiri. Tidak perlu token — pilih paket, isi nama, langsung mengerjakan. Pembahasan langsung terbuka setelah submit.

Tips: jangan tutup tab atau pindah aplikasi saat ujian — aktivitas tersebut tercatat sebagai pelanggaran dan dilaporkan ke guru.

9. Troubleshooting

GejalaSolusi
HP siswa tidak bisa buka halamanPastikan HP terhubung ke Wi-Fi yang sama dengan laptop. Cek Windows Firewall (izinkan Node.js di Private network).
QR code tidak munculKlik tombol Refresh QR di dashboard. Kalau masih kosong, restart server.
Import CSV gagalBaca pesan error — biasanya menyebut baris bermasalah. Periksa kolom kunci dan tanda kutip di teks.
Siswa tidak bisa joinCek: (1) token benar? (2) waktu belum habis? (3) nama terdaftar kalau validasi aktif?
Browser menampilkan halaman basiTekan Ctrl+Shift+R (Windows) atau Cmd+Shift+R (Mac).
Server mati tiba-tibaBuka terminal, jalankan cd ~/tka-local && node server.js, salin error yang muncul.
