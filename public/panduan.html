1Tentang Aplikasi

TKA Local Host adalah aplikasi ujian Try Out berbasis web yang berjalan sepenuhnya di laptop guru tanpa internet. Siswa terhubung melalui Wi-Fi lokal dan mengerjakan dari browser HP/laptop masing-masing.

2Instalasi & Setup Awal

Pertama Kali Install (Windows)

  1. Unduh TKA-Setup-vXX.exe dari link yang diberikan admin.
  2. Klik dua kali file tersebut.
  3. Jika muncul peringatan biru "Windows protected your PC", klik More info → Run anyway.
  4. Ikuti wizard instalasi (Next → Install). Aplikasi terpasang di C:\TKA.
  5. Ikon TKA Local Host muncul di Desktop.

Setup Wizard Pertama Kali

Saat pertama kali membuka aplikasi, Anda akan diarahkan ke halaman Setup Awal:

  1. Isi Nama Sekolah dan NPSN (8 digit angka).
  2. Klik Simpan & Lanjutkan.
  3. Atau klik Lewati dulu jika ingin mengisi nanti di menu Profil Sekolah.
Info: Data sekolah dipakai sebagai header resmi di semua dokumen cetak.

3Profil Sekolah

Menu di sidebar: 👥 DATA & ADMINISTRASI → ⚙ Profil Sekolah

Lengkapi data sekolah Anda:

  • Nama Sekolah (wajib)
  • NPSN (wajib, 8 digit)
  • Alamat
  • Kepala Sekolah & NIP
  • Tahun Ajaran (contoh: 2025/2026)
  • Telepon, Email, Website
  • Logo Sekolah (PNG/JPG, maks 500 KB)
  • Label Cetak — teks yang muncul di dokumen cetak (default: "Tryout TKA Mandiri")

Klik ✏️ Edit Profil untuk mengubah kapan saja.

4Membuat Paket Soal

Menu: 📚 SOAL & UJIAN → Paket Soal

Cara A: Menggunakan Editor Visual

  1. Klik Edit pada paket yang sudah ada.
  2. Di halaman editor:
    • Pilih tipe soal (PG/MCMA/BS)
    • Isi teks soal, opsi, kunci
    • Gunakan tombol a/b, x², √ untuk rumus
    • Klik 📷 Pilih Gambar untuk gambar
    • Isi pembahasan
  3. Live Preview di bawah kotak input menampilkan rumus ter-render.
  4. Klik Simpan.

Mode Acak Soal

  • Acak per tipe — PG dulu, lalu MCMA, lalu BS.
  • Acak total — semua tipe dicampur.
  • Tidak diacak — sesuai urutan asli.
Opsi jawaban (A/B/C/D) tetap diacak per siswa untuk mencegah nyontek.

5Buat Soal dengan AI (Studio)Baru

Menu: 📚 SOAL & UJIAN → 🤖 Buat Soal AI (Studio)

Aplikasi TKA Studio membantu Anda membuat soal dengan bantuan AI (ChatGPT, Gemini, Claude, dll).

Alur Penggunaan

  1. Klik menu Buat Soal AI (Studio) → tab baru.
  2. Isi form: mapel, kelas, topik, jumlah soal per tipe.
  3. Klik Generate Prompt.
  4. Copy prompt ke ChatGPT/Gemini/Claude.
  5. AI menghasilkan CSV soal → copy hasilnya.
  6. Paste ke TKA Studio → klik Parse.
  7. Review soal, edit jika perlu.
  8. Klik Download JSON.
  9. Buka TKA Local Host → Paket Soal → 📥 Import JSON.

6Import CSV & JSON

Import CSV (data massal)

  1. Klik Unduh Template → dapat file CSV.
  2. Buka di Excel/LibreOffice.
  3. Isi kolom sesuai petunjuk.
  4. Save As → CSV UTF-8.
  5. Upload kembali via tombol Import.

Import JSON (dari TKA Studio)Baru

  1. Klik tombol hijau 📥 Import JSON.
  2. Pilih salah satu:
    • Tab Paste JSON — copy-paste langsung
    • Tab Upload File — pilih/drag file .json
  3. Preview soal muncul otomatis (validasi real-time).
  4. Klik Proses Import.

7Data Siswa

Menu: 👥 DATA & ADMINISTRASI → Data Siswa

  1. Unduh Template CSV (kolom: nisn, nama, kelas).
  2. Isi di Excel → Save as CSV UTF-8.
  3. Upload via Import.
  4. Aktifkan toggle Wajib terdaftar.
Nama siswa harus persis sama dengan yang diketik saat login.

8Menjalankan Ujian

Menu: 📊 UTAMA → Dashboard

  1. Pilih paket soal di dropdown.
  2. Klik Mulai Ujian.
  3. Token 8 karakter muncul. Tulis di papan atau tampilkan proyektor.
  4. Klik Perbesar untuk Proyektor → QR code besar.
  5. Siswa scan QR / ketik alamat, isi nama + token.
Penting: Waktu mulai berjalan untuk semua siswa saat Anda klik "Mulai Ujian".

Selama Ujian

Pantau di menu Peserta: nama, kelas, progress, status, pelanggaran.

Akhir Ujian

  1. Server auto-submit saat waktu habis.
  2. Klik Rilis Pembahasan di Dashboard.
  3. Klik Backup ZIP untuk arsip.

9Mode Kiosk & Anti-Cheat

  • Mode Kiosk — saat ujian dimulai, browser masuk layar penuh otomatis.
  • Jika siswa coba keluar (Esc, swipe down di HP), muncul peringatan merah.
  • Pelanggaran tercatat dan muncul di dashboard guru.
  • Acak soal & opsi per siswa.
  • Blokir copy/paste dan klik kanan.
Mode kiosk hanya aktif untuk ujian resmi (dengan token). Mode latihan tidak dipaksa kiosk.

10Rumus & Gambar

Rumus Matematika

Di editor paket, gunakan tombol:

  • a/b → pecahan (contoh: $\frac{1}{2}$)
  • x² → pangkat (contoh: $x^{2}$)
  • √ → akar (contoh: $\sqrt{x}$)

Live Preview di bawah kotak input menampilkan rumus ter-render secara real-time.

Gambar

  • Klik 📷 Pilih Gambar di editor.
  • Bisa juga copy-paste (Ctrl+V) screenshot dari clipboard.
  • Drag & drop file ke area galeri.
  • Siswa bisa tap gambar di HP untuk zoom (lightbox).

11Mode Latihan Mandiri

Siswa bisa berlatih soal di rumah tanpa perlu token guru.

Aktifkan Per Paket

  1. Menu Paket Soal.
  2. Klik Latihan: OFF pada paket → jadi Latihan: ON.

Cara Siswa Akses

  1. Buka halaman utama TKA di HP.
  2. Klik 🎓 Mode Latihan Mandiri.
  3. Pilih paket → isi nama → langsung mengerjakan.
  4. Pembahasan langsung terbuka setelah submit.

12Analisis & Pembahasan

Analisis Butir Soal

Menu: 📊 UTAMA → Analisis

  • Statistik kelas: rata-rata, median, tertinggi, terendah, std dev.
  • Ranking siswa.
  • Analisis per soal:
    • p-value: proporsi benar (>0.7 mudah, <0.3 sulit)
    • D-index: daya beda (≥0.4 baik, <0.2 revisi)
    • Distraktor: sebaran pilihan salah
    • Flag: tanda otomatis soal bermasalah
Butuh minimal 8 peserta untuk analisis daya beda yang bermakna.

Rilis Pembahasan

Klik Rilis Pembahasan di Dashboard setelah ujian selesai.

14Backup & Pemulihan

Backup Otomatis

Setiap kali klik Mulai Ujian, sistem membuat backup otomatis ke folder backups/. Maksimal 14 backup terakhir disimpan.

Backup Manual

Klik Backup ZIP di Dashboard → file .zip terunduh berisi:

  • tka.db — database
  • paket/ — semua paket soal
  • paket/gambar/ — semua gambar

Pemulihan

  1. Matikan aplikasi.
  2. Extract ZIP ke folder instalasi (timpa file lama).
  3. Jalankan aplikasi lagi.

15Panduan untuk Siswa

Login Ujian

  1. HP terhubung ke Wi-Fi yang sama dengan laptop guru.
  2. Scan QR dari guru atau ketik alamat IP (192.168.x.x:3000).
  3. Isi Nama Lengkap + Kelas + Token dari guru.
  4. Klik Mulai Ujian.

Antarmuka Ujian

  • Tampilan Desktop: sidebar navigasi otomatis di kanan.
  • Tampilan HP: klik ☰ Soal untuk grid nomor.
  • Ragu-ragu: klik 🚩 untuk tandai soal, grid jadi kuning.
  • Auto-save: muncul "Tersimpan" setiap jawab.
  • Offline: jika Wi-Fi putus, tetap bisa jawab. Sinkron otomatis saat online.
  • Shortcut: panah kiri/kanan pindah soal, tombol R untuk ragu.

Mode Kiosk

Saat login ujian resmi, layar otomatis masuk mode layar penuh. Jika keluar (Esc), muncul peringatan merah.

Submit

  1. Klik Selesai & Kirim di bawah grid soal.
  2. Konfirmasi muncul menampilkan soal belum dijawab + ragu.
  3. Klik Kirim Sekarang.

Install ke HP (PWA)

  1. Klik menu titik tiga (⋮) di Chrome Android → Add to Home Screen.
  2. Atau klik tombol 📥 Install Aplikasi ke Layar Utama di halaman login.

16Troubleshooting

GejalaSolusi
HP siswa tidak bisa buka halamanCek Wi-Fi sama. Izinkan Node.js di Windows Firewall (Private network).
Windows blokir file .exeKlik "More info" → "Run anyway".
Siswa tidak bisa joinToken salah / waktu habis / nama tidak terdaftar.
Import CSV gagalPastikan separator titik koma (;), tidak ada karakter aneh.
Import JSON gagalCek dengan jsonlint.com. Pastikan field wajib ada.
Modal tidak munculHard reload (Ctrl+Shift+R).
Server mati tiba-tibaBuka aplikasi lagi. Data tersimpan.
Rumus tidak ter-renderPastikan pakai format $...$ (dengan dollar).
