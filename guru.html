Panduan Penggunaan Lengkap

Setup, import soal, analisis, troubleshooting, dan panduan siswa — semua dalam satu halaman yang bisa dicetak.

📖 Buka Panduan
Hotspot Wi-Fi di Laptop
  1. Buka Settings → Network & Internet → Mobile Hotspot (Windows 10/11).
  2. Aktifkan, catat nama & sandi Wi-Fi.
  3. Hubungkan HP siswa ke Wi-Fi tersebut.
  4. Scan QR dari menu Dashboard.

Jika HP tidak bisa membuka halaman, izinkan Node.js di Windows Firewall pada Private network.

Format CSV Paket Soal

Tiga tipe soal didukung dalam satu file CSV:

  • PG — pilihan tunggal. tipe=pg, kunci = satu huruf (a/b/c/d).
  • MCMA — pilihan ganda kompleks. tipe=mcma, kunci = dua huruf atau lebih (misal ac atau a,c).
  • BS — pernyataan benar/salah. tipe=bs, kolom pernyataan_1..5 dan kunci_1..5 = B/S.
Cara Menjalankan Ujian
  1. Buka menu Paket Soal → import CSV (atau gunakan paket yang sudah ada).
  2. Kembali ke Dashboard → pilih paket → klik Mulai Ujian.
  3. Token muncul. Tampilkan QR ke siswa atau bacakan token.
  4. Siswa scan QR / buka alamat, isi nama & token → mengerjakan.
  5. Pantau di menu Peserta.
  6. Setelah selesai: klik Rilis Pembahasan agar siswa bisa lihat pembahasan.
Mode Acak Soal
  • Acak per tipe — PG dulu, lalu MCMA, lalu BS. Cocok untuk ujian formal.
  • Acak total — semua soal dicampur. Cocok untuk kuis singkat.
  • Tidak diacak — urutan sesuai CSV. Cocok untuk soal bertahap mudah → sulit.

Opsi jawaban tetap diacak per siswa di semua mode.

Cara Memakai Gambar di Soal
  1. Upload gambar di menu Gambar — catat nama filenya.
  2. Di CSV, isi kolom img dengan nama file (contoh: peta.png).
  3. Untuk gambar di opsi, isi kolom opsi_a_img, opsi_b_img, dst.
  4. Atau, lewat editor UI: klik Edit pada paket → klik tombol 📷 Pilih Gambar.
