Pencadangan Data (Backup)

Simpan seluruh data ke file ZIP

Mengunduh seluruh database siswa, hasil ujian, paket soal, dan gambar dalam satu file ZIP. Disarankan untuk melakukan backup secara berkala.

Pemeliharaan Server

Hentikan server dengan aman

Matikan server jika ujian telah selesai. Aplikasi akan berhenti dan browser tidak bisa diakses hingga server dinyalakan kembali.

Zona Bahaya (Danger Zone)

Tindakan di sini tidak dapat dibatalkan

Menghapus SEMUA DATA (siswa, soal, gambar, hasil ujian, profil) dan mengembalikan aplikasi seperti baru di-install.
Sistem akan membuat Backup Otomatis ke folder backups/ sebelum menghapus.

Bantuan

Panduan singkat & link ke dokumentasi lengkap

📖 Panduan Penggunaan Lengkap

Setup, import, ujian, analisis, cetak administrasi, troubleshooting — semua dalam satu halaman.

Buka Panduan
🚀 Setup Awal & Profil Sekolah
  1. Saat pertama buka, isi Nama Sekolah dan NPSN di wizard.
  2. Data lain bisa diisi di menu Profil Sekolah.
  3. Data ini otomatis dipakai di header dokumen cetak.
📚 Membuat Paket Soal
  • Editor Visual — klik "Edit" pada paket untuk mengubah soal.
  • Rumus — gunakan tombol a/b, x², √ di editor.
  • Gambar — tombol 📷 atau copy-paste (Ctrl+V).
📥 Import CSV & JSON
  • CSV — data massal dari Excel.
  • JSON — dari TKA Studio.
👥 Data Siswa
  • Import CSV: nisn, nama, kelas.
  • Aktifkan toggle "Wajib terdaftar" untuk validasi login.
▶ Menjalankan Ujian
  1. Dashboard → pilih paket → Mulai Ujian.
  2. Token muncul. Tampilkan QR ke siswa.
  3. Pantau di menu Peserta.
  4. Selesai: klik Rilis Pembahasan.
🛡 Mode Kiosk & Anti-Cheat
  • Layar siswa otomatis masuk mode kiosk (fullscreen).
  • Pelanggaran (Esc) tercatat di dashboard.
📊 Analisis Butir Soal
  • p-value, D-index, Distraktor.
  • Butuh minimal 8 peserta untuk analisis akurat.
🖨 Cetak Administrasi
  • 5 dokumen: Kartu Peserta, Daftar Hadir, Berita Acara, Label Kursi, Tata Tertib.
  • Otomatis pakai data Profil Sekolah.
🎓 Mode Latihan Mandiri
  • Aktifkan toggle "Latihan: ON" di menu Paket Soal.
  • Siswa akses link di halaman login tanpa token.
💾 Backup & Pemulihan
  • Otomatis: setiap Mulai Ujian (14 terakhir disimpan).
  • Manual: Dashboard → Backup ZIP.
