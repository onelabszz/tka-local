Pertanyaan Umum

Apakah benar-benar gratis?

Ya, 100% gratis untuk sekolah Indonesia. Tidak ada biaya lisensi, tidak ada langganan bulanan. Anda hanya perlu membuat akun sekolah — aktivasi diproses dalam 1×24 jam.

Kenapa harus punya akun?

Akun berfungsi untuk: (1) kontrol distribusi agar aplikasi tidak disalahgunakan, (2) dukungan reset password bila guru lupa, dan (3) informasi update versi baru. Data soal dan nilai tetap 100% di laptop sekolah — tidak pernah dikirim ke server.

Apakah data soal saya dikirim ke server?

Tidak. Yang ada di server hanya: email guru, nama sekolah, status akun, dan masa aktif lisensi. Semua soal, gambar, jawaban siswa, dan hasil ujian tetap tersimpan di file database lokal (tka.db) di laptop sekolah Anda.

Bagaimana kalau lupa password?

Hubungi admin sekolah Anda. Admin bisa reset password dari panel admin tanpa perlu install ulang. Jika Anda sendiri admin, hubungi superadmin (pemilik aplikasi) via WhatsApp.

Berapa lama proses aktivasi akun?

Biasanya kurang dari 1×24 jam. Anda akan menerima konfirmasi via email atau WhatsApp dari admin. Setelah aktif, langsung bisa login dan mengerjakan try out.

Apakah ini aplikasi ujian resmi dari Kemendikbud?

Tidak. Ini adalah aplikasi Try Out / Latihan Mandiri independen untuk membantu sekolah mempersiapkan siswa menghadapi TKA. Tidak terafiliasi dengan instansi pemerintah mana pun.

Apakah bisa dipakai tanpa internet?

Bisa. Setelah aktivasi pertama, aplikasi berjalan sepenuhnya offline. Ujian hanya butuh Wi-Fi lokal (hotspot atau Wi-Fi sekolah). Bahkan jika internet mati total, ujian tetap berjalan karena semua data ada di laptop.

Berapa siswa yang bisa mengerjakan sekaligus?

Diuji dengan 30–40 siswa serentak menggunakan satu laptop dan satu HP sebagai hotspot. Untuk 100+ siswa, kami sarankan laptop dengan RAM minimal 8 GB atau server lokal kecil.

Bagaimana cara update ke versi terbaru?

Download installer versi terbaru dari halaman ini, klik dua kali untuk menginstall. Data lama (soal, siswa, hasil ujian) tidak akan hilang karena installer hanya mengganti file program, bukan data Anda.

Apakah bisa dipakai beberapa sekolah sekaligus?

Bisa. Setiap sekolah punya akun sendiri-sendiri. Aplikasi boleh di-install di banyak laptop, tapi setiap laptop aktivasi dengan akun sekolahnya masing-masing. Untuk sekolah dengan banyak guru, admin bisa membuatkan akun guru satu per satu dari panel admin.
